# OTT 구독료 비교 · shakilabs

**▶ 라이브 서비스: <https://shakilabs.com/ott>**

유튜브 프리미엄의 국가별 공식 구독료를 환율 반영 원화로 비교. 가격 조회일과 이용 조건을 함께 표시.

## 주요 도구

- [유튜브 프리미엄 국가별 가격](https://shakilabs.com/ott/youtube-premium)
- [가격 트렌드](https://shakilabs.com/ott/youtube-premium/trends)

전체 서비스 12종: <https://shakilabs.com>

## 스택

Vue 3 (Composition API) · TypeScript · Vite · Tailwind CSS · 공유 UI `@shakilabs/ui`
정적 프리렌더/SSG로 배포하며, 계산 로직은 Vitest 경계값 테스트로 검증합니다.

## 개발

```bash
cd client
npm install
npm run dev
```
